Family sharing

A shared view, only when you turn it on.

Local monitoring needs no account. Family sharing is an optional private test: the nearby iPhone uploads the latest snapshot, and invited adults can read it while the Family screen is open.

This is not a public launch. Remote push alarms are unavailable in the current AltStore family-test setup. Do not rely on the family view for continuous observation or guaranteed alerts.

What is shared

When enabled on the phone near the wearable, Nivvi sends the latest heart rate, oxygen where supported, measurement time, source description, connection status and alert state. Uploads are normally limited to about one every ten seconds. Profile photos, birth dates, notes and the historical readings file are not uploaded.

Who can see it

Each adult uses a separate verified email. Invitations are email-bound, single-use and expire after 24 hours. Invited members have read-only access and cannot change the host phone’s alarm limits. Values older than 30 seconds are hidden. This is not end-to-end encryption between phones.

What it cannot do

If the source phone cannot run or upload in the background, the server cannot obtain readings. Ordinary notifications are best-effort. Stopping sharing cannot recall a screenshot already taken. Sensor accuracy and medical readiness are not established by this test.
